Write post-webinar survey questions and view design advice from the GatherPress event editor.

== Description ==

計算は Composer パッケージ s2j/webinar-survey-service に委譲します。Zoom への添付は S2J Webinar が担当します。

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/` or install the distribution zip.
2. Run `composer install --no-dev` if vendor is not bundled (distribution zip includes vendor).
3. Activate through the 'Plugins' menu in WordPress.
4. Enable GatherPress on the site for event editing.
