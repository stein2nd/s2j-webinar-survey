# S2J Webinar Survey - プラグイン仕様 (ドラフト)

採用・合意前の設計メモとして `docs_mod/` に置き、確定後は `docs/SPEC.md` に移行します。状態はドラフトです。記録日は2026-10-06です。

計算の正は [S2J Webinar Survey Service のサービス仕様](https://github.com/stein2nd/s2j-webinar-survey-service/blob/main/docs_mod/service_spec.md) です。本書は、WordPress 側の編集、保存、助言の表示、コネクタ経由の下書きを定義します。

## 概要

本プラグインは、GatherPress のイベント編集画面で、ウェビナーのアンケート設問を書き、回答の負担と企画上の目的について助言を見るためのものです。管理画面のプラグイン名は「ウェビナーアンケート設問ジェネレータ」です。

スラッグは `s2j-webinar-survey` です。ライセンスは GPL-3.0-or-later です。テキストドメインは `s2j-webinar-survey` です。

両立したいのは、次の2つです。

* 参加者が応えたくなるアンケートである。順番、総数、文章について助言し、回答を躊躇するものを減らす。
* 運営者が、アンケートを次回以降のウェビナー企画に使える。

設問の下書きは、ボタンを押したときに、サイトのコネクタに1回頼むことができます。人が採用するまで文書には入りません。企画上の目的は運営者が書きます。Zoom には送りません。

## 位置付け

| 層 | 名称 | 役割 |
| --- | --- | --- |
| イベント UI | [stein2nd/gatherpress](https://github.com/stein2nd/gatherpress) | イベントの編集画面。本プラグインのコードはフォークに置かない |
| 呼び出し側 | **本プラグイン** | 設問の編集、イベントへの保存、助言文の表示、コネクタ経由の下書き |
| 計算 | [s2j-webinar-survey-service](https://github.com/stein2nd/s2j-webinar-survey-service) | 検査、助言コード、下書きの依頼文と分解。WordPress を知らない |
| 添付 | [S2J Webinar](https://github.com/stein2nd/s2j-webinar) | `ready` の文書を、作成直後にアンケートとして付ける。設問の規則は持たない |

## 目的

初版で、運営者がイベント編集画面から、次を終えることです。

* その回のアンケートに、Zoom の一覧用の内部名と、順序のある設問を書く。
* 単一選択・複数選択・レーティングを先に、短い回答・長い回答を後にまとめる助言を見る。
* 必須の自由記述と、回答者を特定する問いが後ろにないとき、躊躇の助言を見る。
* 各設問に、次回の企画で何を決めるかを書ける。空なら、その旨の助言を見る。
* 不足がない文書を、そのイベントに保存する。
* 必要なら、設問の下書きをボタンで頼み、直してから採用する。

## 非目標 (初版)

* 保存時、画面を開いたとき、cron でモデルを呼ぶこと。
* 人が採用する前の下書きを、文書に書くこと。
* 企画上の目的を、モデルに書かせること。
* Zoom への送信、アンケートの添付、回答と回答率の取り込み。
* 回答から次回のテーマを自動で提案すること。
* 過去の設問の流用、設問だけの台帳。
* セッション中の投票、登録フォームの質問、セッション中の Q&A。
* 公開ページにアンケートを出すこと。回答者の画面は Zoom です。
* WordPress.org への掲載。

## サービスとの境界

本プラグインは、入力した文書と設問総数の上限をサービスに渡します。返った状態、不足コード、助言コードを画面に使います。

| 本プラグイン | サービス |
| --- | --- |
| イベントの入力を渡す。上限の本数も渡す | 検査し、`draft` または `ready` とコードを返す |
| コードを日本語の文にする | 表示文を返さない |
| 入力した文書と状態をイベントに書く | 保存しない |
| ボタンを押したとき、依頼文をコネクタに1回送る | 依頼文を組み立て、返却文を候補に分ける |
| 人が採用した文だけを文書に足す | 候補を文書に書き込まない |
| Zoom に送らない | Zoom のフィールドを持たない |

初版で渡す上限は、サイト設定の値です。未設定のときの初期値は6です。イベントごとに別の上限は持ちません。

## サイト設定

メニューは「アンケート設問」です。操作できるのは `manage_options` を持つユーザーです。

項目は、設問総数の上限だけです。受け付ける範囲は1以上、15以下です。範囲外は保存しません。未設定または空のときは6としてサービスに渡します。

イベント編集のパネルには、この入力を出しません。保存と助言と下書きは、その時点のサイト設定に従います。

## 画面

GatherPress のイベント編集画面に、パネル「アンケート設問」を足します。S2J Webinar のパネルとは別です。公開フックの外側から足し、フォーク本体は改変しません。

操作できるのは、そのイベントを編集できるユーザーです。サイト設定の変更は `manage_options` に限ります。

パネルの冒頭に、「大事な指針」を出します。サイト設定には出しません。文面は次のとおりです。

```
アンケート設計では避けるべき「大事な指針」：
＊ 「すばらしいと思いませんか？」「役に立たなかった理由は？」のように、答えを寄せる、または前提を押しつける誘導文。
＊ 「内容と時間は適切でしたか？」のように、どちらに答えるのか、回答者に負担をかける、一文に判断が2つ入っている文。
```

初版では、誘導と二重の問いを保存のたびに自動判定しません。あとで足すなら、保存を拒まない助言か、ボタンで頼む一文の見直しに限ります。

パネルの項目は、次のとおりです。

* 内部名。補足として、回答者には出さず、Zoom の一覧にだけ出る、と書く。
* 設問の列。追加、削除、並べ替えができる。
* 各設問の、回答者に見せる文。
* 答え方。単一選択、複数選択、短い回答、長い回答、レーティングスケールの5つ。文書ではそれぞれ `single` / `multiple` / `short` / `long` / `rating`。
* 必須にするか。
* 回答者を特定する問いであるか。
* 次回の企画で何を決めるか。補足として、回答者には出ない、と書く。
* 単一選択または複数選択のとき、選択肢の列。追加、削除、並べ替えができる。
* レーティングスケールのとき、最小スコア、最大スコア、低いスコアのラベル、高いスコアのラベル。

画像のアップロード、スキップロジック、マッチング、ランク順、空欄に記入する、は初版のパネルに出しません。初版以降で対応するか否かを検討します。

保存のたびにサービスを呼びます。不足があるときは、パネルに不足を出し、状態は下書きのままです。助言は、不足がなくても出します。助言があっても保存はでき、状態は使ってよい、にできます。

設問が0件の間は、下書きのままです。

## 下書き

下書きは、押したボタンにつき `wp_ai_client_prompt()` を1回呼びます。WordPress v7.0のコネクタが、サイトに接続されたプロバイダに送ります。本プラグインは API キーを持たず、Anthropic、Google、OpenAI のどれかを選びません。

`wp_ai_client_prompt` がないとき、またはテキスト生成ができるコネクタがないときは、ボタンを出さず、「設定 > コネクタ」への案内を出します。検査と保存は、そのままで動きます。

| ボタン | 依頼 |
| --- | --- |
| 設問の下書きを提案 | 上限から、すでに文書にある設問数を引いた件数。空なら上限そのもの。各件は設問文が一文で、単一選択または複数選択なら短いラベルを少数 |
| この設問文の下書き | 開いている1件の設問文 |
| この選択肢の下書き | 開いている単一選択または複数選択の、短いラベルを少数 |

アンケートの提案は、欄の横に一覧で出します。運営者は文を直し、「この設問を足す」で1件ずつ文書にコピーします。使わなかった候補は保存しません。件数が上限に達しているときは、このボタンを出しません。

1件の下書きは、その欄の横に出します。「この下書きを使う」で、その欄にコピーします。コピーしたあとも、運営者は文を直せます。

企画上の目的は、どちらの依頼でも空のままです。運営者が書きます。

コピーした文は、次の保存で検査と助言を通します。候補のままでは、使ってよい状態になりません。

渡すのは、イベントの題名、答え方、運営者が書いた企画上の目的、すでに文書にある設問文です。登壇者のメールと申込者の情報は渡しません。

## 保存

1イベントにつき、アンケートは1つです。保存先は、そのイベントの保護メタ `_s2j_webinar_survey` です。

メタが持つものは、サービス仕様の文書です。状態を含めます。助言コードはメタに残しません。開いたときに、保存済みの文書から計算し直します。

イベントをゴミ箱に移しても、完全削除しても、Zoom 上のアンケートは変更しません。本プラグインは Zoom を呼びません。

## S2J Webinar との受け渡し

`ready` の文書は、上記のメタにあります。S2J Webinar は、作成直後にこれを読んで、アンケートとして付けます。`draft` は読みません。

本プラグインは S2J Webinar が無効でも編集できます。添付の HTTP と、Zoom の設問型への写像は、S2J Webinar とそのサービスが持ちます。本プラグインは Zoom の型名を持ちません。

初版で付ける答え方は、単一選択 (`single`)、複数選択 (`multiple`)、短い回答 (`short_answer`)、長い回答 (`long_answer`)、レーティングスケール (`rating_scale`) です。型文字列は確定済みです。添付の実装は S2J Webinar の後続です。アンケート見出しは未設定ならウェビナータイトル、説明は空です。

内部名は、その添付で Zoom の一覧にだけ出します。回答者に見せる文には使いません。

## 設計方針

[kis-wordpress エコシステム仕様](https://github.com/stein2nd/kis-wordpress/blob/main/docs_mod/specs.md) および [wp-plugin-spec](https://github.com/stein2nd/wp-plugin-spec) に従います。設問の判断はサービス側の純関数です。本プラグインはアダプタです。

フック登録、イベントメタ、サイト設定、編集画面は本プラグインに置きます。

| 借用する原則 | 本プラグインでの意味 |
| --- | --- |
| 依存の向きは外 → 内 | 画面と保存がサービスを呼ぶ。サービスは WordPress を呼ばない |
| 内側はビジネスルール | 検査、助言コード、下書きの依頼文と分解はサービス |
| 外側は詳細 | イベントメタ、サイト設定、パネル、表示文、コネクタ経由の呼び出し |

Composer で `s2j/webinar-survey-service` を require します。参照は [S2J Slug Generater](https://github.com/stein2nd/s2j-slug-generater) が [`s2j/similarity-service`](https://packagist.org/packages/s2j/similarity-service) を Packagist の名前だけで require するのと同じです。`repositories` に `VCS` も `path` も書きません。

無効化ではメタとサイト設定を残します。アンインストールでは、イベントに書いた `_s2j_webinar_survey` とサイト設定を消します。Zoom 上のアンケートは変更しません。

## 実装順

1. 本ドラフトの合意。
2. プラグインの骨格と、サイト設定、イベント編集画面のパネル。保存のたびにサービスを呼ぶ。
3. 不足と助言を、コードから日本語にしてパネルに出す。
4. 下書きのボタンを足す。押したときだけコネクタに1回送り、人が採用した文だけを文書に足す。
5. S2J Webinar が `ready` のメタを添付に使う。本プラグインから Zoom には送らない。

## 本ドラフトの提案

合意前の提案です。

* プラグイン名は「ウェビナーアンケート設問ジェネレータ」。パネル見出しは「アンケート設問」。
* 設問はイベント編集画面で書く。1イベントにつき1つ。メタは `_s2j_webinar_survey`。
* 答え方は単一選択、複数選択、短い回答、長い回答、レーティングスケールの5つ。画像・スキップ・マッチング・ランク・空欄記入は初版のパネルに出さない。
* 下書きはボタンで1回頼む。アンケート全体は上限までの件数を1本で返し、開いている1件は文または選択肢だけを返す。人が採用するまで文書に入らない。企画上の目的は運営者が書く。
* API キーとプロバイダの選択は持たない。WordPress v7.0の `wp_ai_client_prompt()` と、設定のコネクタを使う。コネクタがないときはボタンを出さない。
* 助言があっても保存できる。不足があるときだけ下書きのままにし、S2J Webinar は使ってよい文書だけを読む。
* パネル冒頭に、誘導と二重の問いを避ける「大事な指針」を出す。サイト設定には出さない。初版では自動判定しない。
* 設問総数の上限はサイト設定である。未設定の初期値は6。受け付ける範囲は1以上、15以下。イベント編集には出さない。選択と段階評価は先、自由記述は後。回答者を特定する問いは最後。必須の自由記述は躊躇の助言。
* 企画上の目的と内部名は、回答者に出さない。
* Zoom には送らない。添付と写像は S2J Webinar の後続である。
* 回答率の数値は持たない。
* アンインストールで当該メタとサイト設定を消し、Zoom のアンケートは変更しない。
